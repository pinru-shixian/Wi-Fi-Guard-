介绍（总结作者：WorkBuddy）
## 一、项目背景与定位

在校园网环境下（网络名以 `自己母校英文缩写` 为前缀，如 `PINRU`），代理软件（V2ray / Clash / Sing-box 等）不仅没有加速作用，还会导致网络异常甚至违反校园网使用规范。**Wi-Fi Guard** 是一款常驻 Windows 的自动化守护工具：一旦检测到设备连上校园网，立即并持续地终止代理进程、自动关闭 Windows 系统代理；离开校园网并稳定后，自动恢复代理与系统代理设置，实现"无感切换、全自动管理"。

## 二、主要作用（核心功能）

| 功能 | 说明 |
|------|------|
| **校园网识别** | 通过 `netsh wlan show interfaces` 获取当前 SSID，按可自定义的前缀正则（默认空，请自行填充）匹配校园网及其关联网络 |
| **代理进程查杀** | 检测到校园网时，按进程名列表（默认 11 个：v2ray、v2rayN、xray、clash 全家桶、verge-mihomo、mihomo、sing-box 等）立即终止进程，并在校园网期间**持续拦截**——刚被重新启动也会被立刻杀掉 |
| **系统代理自动化** | 进入校园网自动关闭 Windows 系统代理（写注册表 `ProxyEnable` + WinINet 刷新广播）；离开校园网稳定约 3 秒（可调）后自动恢复原状态 |
| **事件级响应速度** | 500ms 高频轮询 + SSID 防抖（连续 2 次一致才判定切换），连接瞬间即可完成查杀 |
| **图形化界面** | Fluent Design 暗色风格 + Windows 11 液态玻璃（DWM Acrylic），首页状态总览 / 日志页 / 设置页三页导航（纯文字导航，无图标乱码问题） |
| **托盘常驻** | 最小化到系统托盘、托盘菜单快捷操作；关闭窗口时可选"每次询问 / 最小化 / 直接退出"并记住选择 |
| **开机自启动** | 一键写入/移除注册表 Run 项，exe 环境自动适配 `--hidden` 参数 |
| **设置持久化** | 网络前缀、进程列表、轮询间隔、释放延迟、字体大小（8–16pt，适配高分屏）等全部保存于 `%APPDATA%\WiFiGuard\config.json` |
| **运行日志** | 界面实时日志 + 文件日志（`%TEMP%\v2ray_wifi_guard.log`），统计网络切换次数与查杀次数 |

## 三、主要框架与技术架构

### 1. 技术选型：Python + PySide6 (Qt 6)

项目经历了 PowerShell 脚本 → C# WinForms → Python tkinter → **PySide6** 四代演进，最终选定 PySide6，原因：

- `WA_TranslucentBackground` 实现真窗口合成，DWM Acrylic 液态玻璃在此方案下渲染稳定（tkinter 的透明色方案存在点击穿透、花屏等不可修复缺陷，已弃用）；
- 信号槽机制天然解决后台线程与 UI 线程通信问题；
- Microsoft YaHei UI 字体 + 高分屏 DPI 适配，中文渲染细腻，字号可调。

### 2. 双线程架构

```
┌────────────────────────────── 主线程 (UI) ──────────────────────────────┐
│  MainWindow                                                            │
│  ├─ 首页：状态胶囊（SSID / 状态 / 切换次数 / 查杀次数）+ 操作按钮       │
│  ├─ 日志页：QPlainTextEdit 实时滚动日志                                │
│  ├─ 设置页：前缀 / 进程列表 / 轮询 / 延迟 / 自启动 / 字号              │
│  ├─ QSystemTrayIcon 托盘 + 关闭确认对话框                              │
│  └─ QTimer(300ms)：从日志队列取数据刷新 UI                             │
└───────────────▲────────────────────────────────────────────────────────┘
                │ Qt Signal（线程安全投递）
┌───────────────┴──────── 后台线程 (Engine) ──────────────────────────────┐
│  run() 主循环（PollMs=500ms 轮询）                                     │
│  ├─ SSID 检测：netsh → 正则匹配 → 防抖 2 次确认                        │
│  ├─ 校园网态：ctypes+Psapi 枚举进程 → 匹配进程名 → 终止（持续拦截）    │
│  ├─ 代理控制：注册表 ProxyEnable + InternetSetOption(39/37) 刷新      │
│  └─ 放行侧：离开校园网稳定 ReleaseDelaySeconds 后恢复代理             │
└─────────────────────────────────────────────────────────────────────────┘
```

- **Engine（后台线程）**：承载全部守护逻辑，与 UI 通过线程锁保护的配置快照（`get_cfg/update_cfg`）和日志队列通信，绝不直接触碰控件；
- **MainWindow（UI 线程）**：只负责展示与配置编辑，300ms 定时器异步消费日志队列。

### 3. 关键底层技术

| 模块 | 实现方式 |
|------|----------|
| SSID 获取 | `netsh wlan show interfaces` 子进程 + 正则解析 |
| 进程枚举/终止 | `ctypes` 调用 Windows API（Psapi `EnumProcesses` 等），按进程名精确匹配后 `terminate` |
| 系统代理 | 注册表 `HKCU\...\Internet Settings` + WinINet `InternetSetOption(39/37)` 广播刷新，无需重启 |
| 液态玻璃 | DWM API：属性 19/20（暗色标题栏）、33（Win11 圆角）、38（Acrylic 材质），`showEvent` 中重申防失效 |
| 开机自启 | 注册表 `HKCU\...\Run`，frozen 环境自动指向 exe 并带 `--hidden` |
| 界面主题 | QSS 样式表 + `@TOKEN@` 令牌模板替换（accent 色、字号、卡片色动态注入），Fusion 风格基底 |

### 4. 工程化交付

- **PyInstaller** `--onefile --windowed` 打包为独立 exe，脱离 Python/PowerShell 环境，双击即用；
- **frozen 环境适配**：自启动路径、配置读写均兼容打包后的运行形态；
- **干净退出**：统一 `_do_exit()` 流程（停止引擎 → 隐藏托盘 → 关窗 → `QApplication.quit()`），配合 `--smoke` 冒烟测试验证无进程残留；

## 四、典型使用流程

1. 双击 exe 启动（或加入开机自启动）→ 程序最小化进托盘常驻；
2. 连上 `PINRU` 系列 Wi-Fi → 数百毫秒内代理进程被终止、系统代理自动关闭；
3. 校园网期间试图重新打开代理软件 → 会被即刻再次终止；
4. 切回其他网络且稳定 3 秒 → 系统代理恢复、可正常使用代理软件；
5. 所有事件实时记录在日志页，可随时在设置页调整规则。
